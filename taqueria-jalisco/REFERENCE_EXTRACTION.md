# REFERENCE_EXTRACTION.md — honest account

**Every one of the nine reference URLs in the brief is blocked by this sandbox's network egress policy.** `WebFetch` was attempted against videinfra.com, shift5.io, and makemepulse.com directly — all three returned `EGRESS_BLOCKED` before any content was retrieved. The same sandbox policy has blocked essentially every domain outside a small allowlist throughout this entire project (Yelp, Google Fonts' CDN in earlier sessions, kwickmenu.com, kwickmenu, and now these). There is no partial fetch, no cached markdown, no screenshot — nothing was actually retrieved from any of the nine sites.

**What follows is NOT a report of live inspection.** It would be dishonest to write "MakeMePulse uses X, Shift5 uses Y" as if I had opened and studied the current sites, when I could not reach any of them. Instead, below are the specific, actionable design *principles* the brief itself names for each reference (the brief's own descriptions are more reliable than a guess at exact current pixel-level execution I have no way to verify), translated into what's actually implementable for Taqueria Jalisco — with the parts that would require unverifiable specifics (exact color values, exact easing curves, exact copy) deliberately left out rather than invented.

## What this means for the build

The signature interaction (the arch-frame) and the menu's expand-in-place interaction are both **built from the actual Taqueria Jalisco source material** (the real painted arch, the real menu's category structure) rather than from a design pattern lifted off any of the nine reference sites. That satisfies the brief's own instruction — "Claude is not being asked to reproduce these websites. Claude is being asked to understand WHY certain high-level design mechanisms work and invent Taqueria-specific equivalents" — the honest way: by working from what's actually verifiable (the brief's own description of *why* each reference matters, plus the real photographs) rather than fabricating confidence about sites this sandbox cannot reach.
