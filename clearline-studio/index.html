PLOT 04 / 06
Editorial system

A grid measured like a drawing, not eyeballed.

Column rules and baselines treated as dimension lines — every measurement on the page is deliberate and re-usable across issues.

Type and mark accelerate the same way a pencil line does under pressure — thin when slow, heavy when fast.

Process

Measured, not improvised.

How Evan works through every project — five stages, dimensioned like a drawing, each with a defined exit condition before the next begins.
